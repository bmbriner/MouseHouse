mousehouse!
game where you are a mouse, running away from a cat while finding the exit door.
game shuts down once you unlock the exit door. 
doors are all randomly generated every time. 
if you run into the cat, you get -10 points. 

Bugs:
- cat's walking path is based on AI. 
  the cat will stand still if the cat is going up in the elevator to get to the floor that you are on, 
  and you leave the floor to go down before the cat lands on the floor.
  the cat will then continue moving once you land on the floor the cat is on again.
- game over screen is also buggy.
